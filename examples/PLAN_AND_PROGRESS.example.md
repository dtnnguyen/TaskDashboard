# Plan & Progress

> An example plan to start from: replace these projects with your own.
> TaskDashboard reads the `## Milestones` section; everything else is notes for you.
>
> - Project: `### <status> Name (target: YYYY-MM-DD)`. The target is optional
> - Status: 🟢 active · 🔁 habit · ⏸️ later · ✅ done (active projects make up the overall %)
> - Goal: `- [ ] text`, done: `- [x] text — YYYY-MM-DD`. The date is optional; without one, the day you tick it is recorded
> - A goal can have its own `(target: YYYY-MM-DD)` and shows as overdue once it passes
